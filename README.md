# 🌀 원래 모양으로 되돌아가려는 힘 실험실

중학교 1학년 과학 「Ⅴ. 힘의 작용」 — **탄성력**.
학습 목표 **탄성력의 크기와 방향을 설명할 수 있다.**

## 어떻게 여나

**설치할 것이 없습니다.** `index.html` 을 더블클릭하면 바로 열립니다.

| 화면 | 파일 | 하는 일 |
|---|---|---|
| 🌀 실험실 | `index.html` | 용수철을 눌렀다 당겼다 하고, 추를 매달아 본다 |
| 📝 학습지 | `worksheet.html` | 15문항 (12문항 자동 채점) · 종이로도 뽑을 수 있다 |
| 🔑 정답지 | `worksheet.html?key` | 정답만 A4 **한 쪽**. 선생님용 화면에서 들어간다 |
| 🗂️ 선생님용 | `teacher.html` | 제출한 PDF 를 파일 이름만 읽어 정리한다 |

## 무엇을 보여 주나

- **🤏 누르고 당기기** — 누를 때도 당길 때도, **준 힘 화살표와 탄성력 화살표가
  언제나 같은 길이로 반대 방향**을 향합니다. 세게 할수록 둘이 함께 자라요.
- **🪝 추를 매달면** — 추를 하나씩 늘리면 용수철이 **무게에 비례해서** 늘어납니다.
  학습지의 실험표가 옆에 함께 있어 값을 바로 견줄 수 있어요.
  표에 없는 **추 7개**도 예측해 볼 수 있습니다.
- **⚖️ 용수철저울** — 거꾸로, **늘어난 길이를 재어 무게를 알아냅니다.**

## 이 앱이 남기고 싶은 두 문장

> **탄성력은 준 힘과 크기가 같고 방향이 반대다.** 많이 변형될수록 커진다.
>
> **늘어난 길이는 무게에 비례한다.** 그래서 늘어난 길이를 재면 무게를 알 수 있다.

두 번째 문장이 곧 **용수철저울**입니다.
